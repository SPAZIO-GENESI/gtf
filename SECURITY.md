# Security policy

Report vulnerabilities to: **it@spaziogenesi.org**.

Full responsible-disclosure policy (scope, safe harbor, response times) at
[attestazione.spaziogenesi.org/sicurezza/](https://attestazione.spaziogenesi.org/sicurezza/),
compliant with `security.txt` ([RFC 9116](https://www.rfc-editor.org/rfc/rfc9116)):
[`/.well-known/security.txt`](https://imgauth.spaziogenesi.org/.well-known/security.txt).

Scope of this repository: the Genesis Trust Framework engine (`core/`) and the
public transparency registries it generates (`tenants/`) — not the attested
service itself, which is covered by the same policy under its own repository.
